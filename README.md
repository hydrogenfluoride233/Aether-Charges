# Aether Charges / 天境射弹

![logo](logo.png)

中文 | [English](README_EN.md)

或许你已经厌倦了和烈阳巨灵打半个小时的保龄球？又或者，你也想试一次当 Boss 的感觉——把它们扔过来的东西，原样扔回去？那我想这个模组适合你。

**天境射弹**为天境添加了四样射弹，以及各自对应的权杖：

| 物品 | 弹体 | 效果 |
|---|---|---|
| 冰霜弹/冰霜权杖 | 冰结球 | 7 点伤害并减速；命中烈阳巨灵时可以把它冻住 |
| 炽炎弹/炽炎权杖 | 滚炎球 | 15 点伤害并点燃目标 |
| 阳雷弹/阳雷权杖 | 风暴雷球 | 5 点伤害，落点召下一道闪电 |
| 流云弹/流云权杖 | 境云冰晶 | 不造成伤害，沿弹道把目标推开 |

射弹是一次性的；权杖从地牢的 Boss 宝箱里开出，可以反复使用。射弹的伤害、击退、弹速都比权杖弱一档——权杖才是能长期依靠的那件。

权杖可以附魔：

| 附魔 | 效果 |
|---|---|
| 晶化 | 强化元素效果：冻结更久、燃烧更久、落雷概率更高、击退更远 |
| 迅捷 | 缩短冷却 |
| 连发 | 每次多打一发，略微散开 |

附魔书出没在地牢的普通箱子里；装了 Explore Ruins: The Aether 的话，它的遗迹箱子也会掉；在天境钓鱼也有小概率钓上来。

伤害、冷却、弹速、是否落雷、各种倍率都可以在 `config/aether_charges-common.toml` 里调。

想了解每件东西的来历，把它们放进《天境传说》里。

## 联动

- **Deep Aether**：流云弹与流云权杖只在装了它时提供
- **Deep Aether ＋ Aether: Treasure Reforging**：四种权杖可以在联结器里合成——自然权杖 ＋ 对应射弹 ＋ 对应重铸材料
